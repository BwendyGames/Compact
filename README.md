A unfinished, tile-based, turn-based, sci-fi strategy game in Game Maker Studio 2.  My intention for making this is to give a good foundation, for anyone to make such a game. There's not a lot here and I'm not sure if I'm going to continue it, but what is here is very dynamic and scalable.
